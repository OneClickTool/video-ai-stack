# Video AI Stack — làm video bằng AI, biết rõ từng món

Trang: **https://oneclicktool.github.io/video-ai-stack/**

Các luồng làm video bằng Claude Code (TikTok faceless, hook meme → app, hoạt hình cutout, tóm tắt truyện, đồ hoạ kênh,
video cho app) — mỗi luồng xài AI gì, giọng TTS nào, Whisper để làm gì, font, hiệu ứng, render bằng Remotion hay Godot.

Theme chép từ [Product Growth Playbook](https://oneclicktool.github.io/product-growth-playbook/) (MkDocs Material).

```bash
pip install "mkdocs<2" "mkdocs-material==9.*"
python -m mkdocs serve
```

Push lên `main` → GitHub Actions build và deploy Pages.
